Welcome! This organisation hosts the **assignment repositories** for SM-2302. All lecture notes, announcements and deadlines are on **Canvas**.

## What you'll use

| Tool | Used for |
| --- | --- |
| **MATLAB** | Numerical computation and visualisation |
| **Python** | Scientific programming and data analysis |
| **LaTeX** | Typesetting mathematical documents |

## How assignments work

1. **Accept the assignment** using the GitHub Classroom invite link posted on Canvas.
2. A **private repository** is created for you here: `SFM-2026/<assignment>-<your-username>`.
3. **Clone** it, work on your solution, then **commit and push** regularly.
4. Your **last push before the deadline** is what gets marked. Check on GitHub that your work is actually there.

## Good practice

- Commit little and often, with clear messages.
- Read the `README` in each assignment repository before starting.
- If an assignment has automated tests, check the **Actions** tab for results.

## Academic integrity

Your repositories are private to you and the teaching team. Do not share your code or copy others' work. UBD academic integrity regulations apply to every submission.
